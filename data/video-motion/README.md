# Motion-video manifests

One `<slug>.json` per article film, in the format described in
`docs/video-motion-playbook.md`. `npm run video:motion:verify` (part of
`npm run verify`) checks every manifest here.

None are committed at the moment. The nine manifests that used to live here
built narrated films that were removed from `public/videos/` on 2026-11-12,
because their narration named organisations as partners, pitched a budget, or
stated correction or verification capabilities our results do not support (see
`RETIRED_FILMS` in `scripts/lib/film-listing.mjs`). Git history keeps them.
